# z0/OMP extension seam and patch-surface ledger (M5)

**Scope:** read-only inventory for [mobile roadmap #158](https://github.com/kvnloo/oh-my-pi/issues/158), traced to [issue #80](https://github.com/kvnloo/oh-my-pi/issues/80). This is not an extraction, a working z0 bridge, or a request to patch core. All implementation links below are pinned to the inspected fork-main commit [31147f9d1a76608549821c3759f8487b4d66c72d](https://github.com/kvnloo/oh-my-pi/commit/31147f9d1a76608549821c3759f8487b4d66c72d); a newer main needs a fresh audit.

**Ownership rule:** OMP owns model execution, persistent session state, approval policy, extension loading and lifecycle. An out-of-tree z0 extension may observe or propose bounded changes using the documented APIs, but it does not gain permission to publish, execute privileged actions, claim a verified outcome, or replace an independent verifier.

## Review and evidence checklist

- [x] Every hook category links to a concrete current-main source symbol or implementation at the same immutable SHA.
- [x] Owner authority is separated from extension suggestions, notifications, and unverified downstream outcomes.
- [x] Existing candidate PRs are linked as related *branches*, not treated as shipped behavior or authorization.
- [x] No production scheduler, adapter, provider default, z0-specific core branch, or second extension runtime is added.
- [ ] Execute the focused async managed-timer regression: `bun test packages/coding-agent/test/extensibility/managed-timers-promise-rejection.test.ts`.
- [ ] Run `bun check` and the CI workflow. **CI / check** (job: **Lint, type check & web build**) validates workspace/type/lint; **CI / test_coding_agent_runtime** (job: **Test coding-agent runtime/session (TS)**) runs the extension regression through the current test partition.
- [ ] Independently verify proposed out-of-tree behavior with real hosts and source identity before treating any candidate as ready for promotion.

**Limit:** a source inventory and synthetic regression are not live provider, z0 bridge, TUI, desktop, or hardware qualification. Green GitHub Actions is not approval to merge or publish upstream.
