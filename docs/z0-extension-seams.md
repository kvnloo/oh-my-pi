## Extraction classification and limits

- **EXTENSION_EXTRACTABLE candidates:** optional z0-owned context projection, provider settings, bridge tools, lifecycle observations, managed sampling and UI projection. These are possible external consumers of existing OMP APIs, **not** completed extractions.
- **CORE_REQUIRED:** current OMP context dispatch, provider/auth routing, tool schema/approval checks, session teardown, timer lifecycle and UI-host capability gating. These remain native authority.
- **GENERIC_UPSTREAM_CANDIDATE:** none proven missing by this source audit. A generic core change needs a supported failure, narrow regression and native verification before a patch.
- **EXPERIMENT_ONLY:** [#77](https://github.com/kvnloo/oh-my-pi/pull/77) and [#107](https://github.com/kvnloo/oh-my-pi/pull/107) are draft carriers, not main behavior. Do not mark historical diffs **STALE** without exact-head comparison.

No z0-specific core edit, scheduler, separate extension runtime, live collector, provider default, secret access or upstream publication is proposed. In particular, model suggestions, session events or UI content do not authorize file writes, payments, credentials, publishing or other consequential operations.

## Source-link checklist / CI verification

1. Review each immutable source link against the referenced SHA. The offline regression `bun test packages/coding-agent/test/extension-seam-ledger.test.ts` verifies all seven rows, nonempty ownership/gap/candidate fields, matching SHA, and each linked symbol at its cited source line.
2. **CI / check** (`bun run ci:check:full`) covers repository lint, formatting and types; **CI / test_coding_agent_runtime** (`bun run ci:test:coding-agent:runtime`) selects `extension-*.test.ts` and runs the source-link test. These checks validate this ledger, not an actual out-of-tree z0 adapter.
3. Native extension smoke, Windows/TUI/provider sessions, automated upstream rebase/range-diff, heavy integration tests and exact-host evaluation remain external follow-ups to [#80](https://github.com/kvnloo/oh-my-pi/issues/80). Do not mark those checks passed from a doc-only green run.
