Usage: omp [options] [prompt]

oh-my-pi - A powerful coding agent CLI

Options:
  -p, --print <prompt>      Execute prompt in non-interactive mode
  --no-session             Don't create/load a session
  --version                Display version information
  --help                   Display this help message

Commands:
  doctor                   Run diagnostic health checks
  models [provider]        List available AI models
  config <operation>       Manage configuration (list, get, set)
  sessions                 List and manage sessions
  stats                    Show statistics dashboard

Examples:
  omp doctor               Run installation diagnostics
  omp models anthropic     List Anthropic models
  omp -p "Hello"          Execute single prompt
