PYTHON DEPENDENCY DISTRIBUTION ROLE
===================================

omp-rpc has no third-party runtime dependencies. robomp declares FastAPI,
Uvicorn, HTTPX, Pydantic, pydantic-settings, python-dotenv, Click, and omp-rpc
as ordinary installer-resolved dependencies. The Python wheels do not vendor
those projects; each dependency remains a separately installed distribution
carrying its own license metadata and files. Container/system assemblers must
retain those independently installed distributions' notices.

crates/vendor/brush-core/LICENSE

This directory contains a vendored, locally-patched copy of brush-core from the
brush shell project (https://github.com/reubeno/brush), used under the MIT
License. It is wired into the workspace via `[patch.crates-io]` so these
modifications can be maintained against the published release (brush-core
0.5.0).

  Copyright (c) 2024 reuben olinsky

Local modifications include: Windows path handling fixes (drive-alias and
rooted-path normalization in globs), an async background-PID fix for the nohup
wrapper, treating `/dev/null` as poll-ready to avoid an infinite poll on macOS,
and indentation/formatting standardization. The remaining logic tracks upstream
so behavior matches the published crate.
